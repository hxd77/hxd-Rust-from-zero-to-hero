## 🧩 一、为什么要先学 Plonk

因为：

* **HyperPlonk 是 Plonk 的改进版本**；
  
* **WHIR 借鉴了 Plonkish 框架**，只是去掉了 FFT 与 pairing 承诺；
  
* 它们的论文、实现和证明逻辑几乎都用 “Plonkish Constraint System (PCS)” 语言描述。
  

简单说：  
如果你不懂 Plonk，你看 HyperPlonk 的论文时会对“permutation argument”、“witness polynomial”、“selector”、“gate”、“commitment opening”等概念完全摸不着头。

* * *

## 🧠 二、Plonk 的核心知识（只学这些就够）

我帮你划出了“理解 HyperPlonk / WHIR 必要且足够”的知识点，不用啃完整数学细节。

| 模块                                    | 概念                                                      | 为什么重要                                                   |
| --------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------ |
| **电路表示**                            | 约束系统（Constraint System） / 自定义门（Custom Gates）  | Plonk 是从电路出发，把算术电路翻译成多项式约束。             |
| **Witness 多项式**                      | 把电路输入、输出、内部变量编码成多项式 $a(X), b(X), c(X)$ | HyperPlonk 也使用类似结构，只是扩展到多变量多项式。          |
| **选择器（Selector）多项式**            | 表示不同门的系数，例如 $q_M, q_L, q_R, q_O, q_C$          | 理解 Plonkish 结构的基础。                                   |
| **Permutation Argument**                | 确保变量在不同门之间连接一致（“同一个 wire 的一致性”）    | 是 Plonk 体系的核心思想，HyperPlonk 对它有线性化改进。       |
| **多项式承诺（Polynomial Commitment）** | 用 KZG 承诺电路多项式并零知识验证                         | HyperPlonk 替换为更高效的线性承诺，WHIR 则换成哈希承诺。     |
| **FFT 与 Lagrange Basis**               | 用 FFT 快速计算多项式评估                                 | HyperPlonk/WHIR 都是对 FFT 依赖的改进，所以要理解“为什么原版要用 FFT”。 |
| **零知识 / 随机化技巧**                 | Blindings, randomness                                     | 所有改进版本仍保留这些思想。                                 |

## 🔬 三、学习路线推荐（从 Plonk 到 HyperPlonk / WHIR）

### 第一步：快速掌握 Plonk（1–2 周）

📚 推荐资料：

1. **原论文**：  
    🔗 “Plonk: Permutations over Lagrange-bases for Oecumenical Noninteractive arguments of Knowledge” (2019)
    
2. **通俗教程**：
  
    * ZK Hack 的 Plonk Explained 视频系列
      
    * Blog: “Understanding Plonk in simple terms”
      
    * Vitalik 的文章：《An approximate introduction to how PLONK works》
      
    * YouTube: _“Plonk Explained” by zkStudyClub (Bünz, Fisch)_
      

📌 目标：理解电路 → 多项式 → 承诺 → 验证的完整路径。  
不要求推公式，只要你能画出数据流。

* * *

### 第二步：理解 Plonkish 框架（1 周）

这是很多现代 zk 系统的抽象统一层，包括：

* Halo2、HyperPlonk、Plonky2、zkSync、Jolt 等都基于此。
  

📚 推荐：

* Halo2 设计文档（Zcash）
  
* “What makes a SNARK Plonkish?” — excellent blog post
  
* Plonky2 代码的 constraint builder 模块
  

📌 目标：明白什么是 “Plonkish constraint system”，能读懂电路 DSL 语法，如：

```rust
a * b = c
a + b = d
```

如何被转换成 gate 约束和多项式形式。

* * *

### 第三步：学习 HyperPlonk（2–3 周）

📚 核心论文：

* 🔗 HyperPlonk: Plonk with Linear-Time Prover and Polylogarithmic Verification (ePrint 2022/1355)
  

📌 重点：

* 理解“多变量多项式（multilinear polynomial）”代替 FFT；
  
* 理解“sumcheck 协议”如何压缩约束；
  
* 比较 Plonk 的 $O(n \log n)$ 与 HyperPlonk 的 $O(n)$；
  
* 注意 HyperPlonk 如何改造 permutation argument（线性时间一致性验证）。
  

* * *

### 第四步：学习 WHIR（2–3 周）

📚 核心资料：

* 🔗 WHIR: Algebraic Hash-based Recursive Proofs without FFTs (2024)
  
* GitHub: [WizardOfMenlo/whir](https://github.com/WizardOfMenlo/whir?utm_source=chatgpt.com)
  

📌 重点：

* 理解为什么要“去除 FFT”；
  
* 理解 hash-based commitment 的思想；
  
* 理解其 recursion-friendly 的设计；
  
* 思考与 HyperPlonk 的对比：线性时间 vs 无 FFT vs Hash 承诺。
  

* * *

## 🧭 五、学习建议（结合你的背景）

你之前提到的研究方向是：

> “基于同态加密的可验证安全聚合”，研究生方向偏 GPU 加速。

那么推荐路线是：

1. ✅ 先熟悉 **Plonkish 框架**（电路、约束系统、承诺结构）；
  
2. ⚡ 再重点学 **HyperPlonk**（你可以研究它的 GPU 加速实现）；
  
3. 🧩 同时关注 **WHIR**（如果你以后想研究验证效率或递归验证优化）；
  
4. 🔍 最后结合你的 DEVA 协议，看能否用 zk 来验证聚合正确性或掉线恢复正确性。
