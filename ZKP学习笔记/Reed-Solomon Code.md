# Reed-Solomon Code

## Overview

### RS 码是什么？

RS 本质上是一种在传输数据时纠正错误的方法。就是这样。简单。

### 如何工作

通过增加数据的冗余性。

核心思想是扩展发送的数据，使其更具有容错能力。如果传输的某些部分出现损坏，额外的信息有助于重建原始消息。所以，是的，数据会更大，但至少它会被正确传输。

回到我们的二维码示例，图像由许多黑白方块组成。想象一下，你已经准备好了一个二维码，总共有 400 个方块。

事实上，你的相机实际上不需要所有 400 个方块来理解数据。它可能只需要 300 个（例如）。额外的方块是为了补偿可能出现的数据丢失，比如损坏或部分遮挡的图像。

最后，一个 RS 解码算法会处理这些方块，并重建正确的数据，即使有些方块缺失或错误。



## 编码理论

*编码理论是研究编码及其在特定应用中的性能的学科。编码用于数据压缩、密码学、错误检测和纠正、数据传输和数据存储。*

一些关键术语:

+ code: 一组用于表示信息的符号集合
  + 例如英文字母表是一种编码
  + 数学中的0-9也是一种编码
+ codeword: 代码中的一个特定符号序列
  + 例如：在英文字母表中，“computer”是一个码字，它由字母表中的八个符号组成。
  + 符号可以重复，所以“teddav”也是一个有效的码字。
  + 对于数字，任何数字（例如，2734）都是一个码字。



### RS codewords

RS 中的码和码字是什么？

在 Reed-Solomon 码中，我们使用素有限域，这意味着我们的数据表示为域中的一组数字。

码字的长度由发送方和接收方预先确定，以便双方都知道要期待什么。稍后，我们将看到 RS 码如何编码消息和冗余。

Example:

如果我们决定使用字段 $\mathbb{F}_{113}$ :

+ 我们的码（或字母表）将包括从 0 到 112 的所有数字（包含在内）。
+ 码字长度是预先选择的。假设我们决定长度为 9，那么一个可能的码字可以是：[106, 57, 14, 109, 66, 99, 46, 28, 8]



## 面对现实

### 参数

+ `n` → 码字长度。这是整个传输的数据，包括冗余。
+ `k` → 消息长度。这是发送者想要传输的实际消息，不包括冗余。

简单来说：如果我们想要发送一个长度为 `k` 的消息，我们必须将其扩展到长度 `n` 。

这意味着 `n - k` 符号用于错误纠正，我们最多可以纠正 $\frac{n-k}{2}$ 个错误。



### 编码消息

为了这一切魔法能够运作，我们需要多项式。

RS 码的核心思想是：

1. 将原始信息编码为一个多项式。
2. 在 `n` 个点上求多项式的值。



### 为什么有效

RS 码依赖于一个 `d`次 多项式在由 `d+1` 个点唯一确定的原理。如果某些点损坏，只要我们至少有 `d+1` 个有效点，仍然可以重建原始多项式。

在 RS 码的情况下，我们需要略多于 `d+1` 个点来确保我们正在插值正确的数据。

Example:

说 `n = 10` 和 `k = 5` 。我们可以插值得到两个不同的多项式：

+  一个从点 1 到点 5
+ 另一个从点 6 到点 10

没有额外的约束条件，没有办法确定哪一个是正确的。



### 多项式插值

对于一条直线（一个一阶多项式），两个点就足够确定其方程。如果我们有一个第三点且它不在这条直线上，我们就知道存在错误。

```python
F = GF(101)
R = F['x'] #一元多项式环，单变量多项式x

# 我们想要一个5次多项式
d = 5

# 我们选取6个随机点（d + 1）
# 这些将是我们的`y`值
ys = [F.random_element() for _ in range(d + 1)]
print("y 的值: ", ys)

# 我们的`x`值将是0到d
points = [(x,y) for (x,y) in enumerate(ys)]

P = R.lagrange_polynomial(points)
print("points1: ", points)
print("P1: ", P)

# 现在我们再添加几个点
# 这些点仍然在同一个多项式上
points.append((6, P(6)))
points.append((7, P(7)))

# 如果我们再次进行插值，会得到相同的多项式
P2 = R.lagrange_polynomial(points)
assert P2 == P
print("points2: ", points)
print("P2: ", P2)

# 最后我们只修改了1点
points[0] = (0,0)
P3 = R.lagrange_polynomial(points)
print("points3: ", points)
print("P3: ", P3)
```

## 编码

我将使用 Sage 来使用 Reed-Solomon 码编码数据。完成后，我们将进入解码，这有点棘手。

在这个例子中，我们将编码消息"TEDDAV"。

+ 由于 `k` 代表我们消息的长度，这里我们有 `k = 6` ，这意味着多项式的次数为 5。
+ 编码后的码字长度为 `n = 13` 。为什么是 13？没有特殊原因，我只是随机选的

在进入代码之前，让我们快速回顾一下编码过程：

1. 将我们消息中的每个字母转换为相应的数值。
2. 使用这些数值作为系数来构造一个多项式 P。
3. 通过在 13 个不同点（从 0 到 12）评估 P 来引入冗余，这给我们提供了最终的码字。

```python
F = GF(101)
R = F['x']

message = "TEDDAV"
message = [ord(c) for c in message] #转换字母为数字
print("message", message)

k = len(message)
n = 13

# 我们根据该消息定义多项式P
P = R(message)
print("P: ", P)

# 我们在n个点上对P进行评估，以得到我们的码字
codeword = [P(i) for i in range(n)]
print("codeword: ", codeword)
```

现在我们的码字已经准备好了，可以传输。接收方收到后将会检查错误。

### 无错误解码

接收器已经知道这些参数：

-   `k = 6` → 原始消息长度
-   `n = 13` → 码字的总长度

由于他们期望码字长度为 13，并希望恢复长度为 6 的消息，他们遵循以下简单的验证过程：

1. 从接收到的点中插值多项式 P。
2. 检查它的次数：
   1. 如果次数为 5 → 码字有效，我们可以恢复消息。
   2. 如果次数大于 5 → 发生错误。

我们来检查：
```python
# 检查码字是否有效
codeword = [84, 36, 83, 16, 10, 36, 81, 65, 61, 10, 42, 90, 9]
points = [(x,y) for (x,y) in enumerate(codeword)]
P = R.lagrange_polynomial(points) #根据码字插值多项式

if P.degree() == 5:
    print("我们得到了消息!")
else:
    print("这里有错误。")
    exit()

coefficients = P.coefficients(sparse=False) #得到多项式系数
recovered_message = [chr(m) for m in coefficients] #把系数转换为字母
print("消息: ", recovered_message)
```

```

```

我们已经成功发送并解码了一条 Reed-Solomon 编码的消息。

## 解码

解调 Reed-Solomon 码有多种方法。今天我们将使用 Berlekamp–Welch 算法。

为了简化说明，我将从维基百科的这个例子开始，逐步分解。

Example:

![wikipedia example](https://teddav.github.io/img/blog/rs-wikipedia.png)

### 设置

我们定义以下参数：

+ Alphabet:  $\mathbb{F}_{929}$ (所有从0到928的数字)
+ Codeword length: n=7
+ Message length: k=3
+ Evaluation points: $a_i=0,1,2,3,4,5,6$

我们能纠正多少个错误？

公式是：

$$
\frac{n-k}{2}=\frac{7-3}{2}=2
$$
消息多项式是：
$$
P(x)=3x^2+2x+1
$$
我们通过将消息值作为系数来简单地构建它。

码字是通过在 $a_i$ 处评估 $P(x)$ 生成的：
$$
c = { P(0), P(1), ... , P(6) } = { 1, 6, 17, 34, 57, 86, 121 }
$$
接收器收到 b（c 的一个可能已损坏的版本），他们的任务是确定是否存在错误并恢复原始消息。



### 错误多项式

为了检测和纠正错误，我们引入一个错误多项式 $E(x)$ ，它满足以下条件：

+ $E(x)$ 的次数等于**最大错误数：**次数 = 2
+ 首项系数为 1，所以 $E(x)=x^2+e_1x+e_0$
+ $E(a_i)=0$ ，如果索引 i 处有错误（我们目前还不知道这些位置）

所有接收到的值 $b_i$ 必须满足的关键方程是：
$$
b_i*E(a_i)=E(a_i)*P(a_i)
$$
我们有两种情况：

+  有一个错误 → $b_i$ 是错误的，而 $E(a_i)=0$ （根据定义）
+ 没有错误 → $b_i=P(a_i)$

由于 $P(a_i)$ 未知，我们定义一个新的多项式 $Q(x)$ ，使得：
$$
Q(a_i)=E(a_i)*P(a_i)
$$
因此，我们可以将我们的方程改写为：
$$
b_i*E(a_i) - Q(a_i)=0
$$
由于 $E(x)$ 的次数是 2，且 $P(x)$ 的次数是 2 → $Q(x)$ 的次数将是 4。用未知系数展开：
$$
b_i(e_0+e_1a_i+e_2a_i^2)-(q_0+q_1a_i+q_2a_i^2+q_3a_i^3+q_4a_i^4)=0
$$
我们知道（根据定义）， $e_2=1$ ，我们得到：
$$
b_i(e_0+e_1a_i)-(q_0+q_1a_i+q_2a_i^2+q_3a_i^3+q_4a_i^4)=-b_ia_i^2
$$
如果我们将其放入矩阵中，则得到以下结果：

![solve matrix](https://teddav.github.io/img/blog/rs-matrix.png)

### 求解矩阵

我们解这个矩阵，并找到 E 和 Q 的系数。

“解矩阵”是什么意思？就像解一个方程组一样。基本上，上面的矩阵就像解以下方程：
$$
b_1e_0+e_1b_1a_1-q_0+q_1a_1+q_2a_1^2+q_3a_1^3+q_4a_1^4=-b_1a_1^2 \\ b_2e_0+e_1b_2a_2-q_0+q_1a_2+q_2a_2^2+q_3a_2^3+q_4a_2^4=-b_2a_2^2 \\ b_3e_0+e_1b_3a_3-q_0+q_1a_3+q_2a_3^2+q_3a_3^3+q_4a_3^4=-b_3a_3^2 \\ ... \\ b_7e_0+e_1b_7a_7-q_0+q_1a_7+q_2a_7^2+q_3a_7^3+q_4a_7^4=-b_7a_7^2
$$
一旦我们解出系数 $e_0,e_1,q_0,q_1,q_2,...$ ，我们就能恢复错误多项式 $E(x)$ 和 $Q(x)$

由于我们知道 $Q=E*P$ ，我们现在可以恢复原始消息多项式：
$$
P=\frac{Q}{E}
$$
我们成功了！即使消息中存在一些错误，我们仍然恢复了原始信息。


### 回到我们的示例

让我们继续使用原始码字的前面例子：

$$
[84, 36, 83, 16, 10, 36, 81, 65, 61, 10, 42, 90, 9]
$$
由于可纠正的最大错误数是：
$$
\frac{n-k}{2}=\frac{13-6}{2}=3
$$
我们将引入三个错误，导致接收到的数据：
$$
[30, 36, 83, 16, 10, 36, 60, 65, 61, 100, 42, 90, 9]
$$
现在，让我们来建立我们的方程组：

+ 定位多项式 $E(x)$ 的次数为 3
+ 评估多项式 $Q(x)$ 的次数为 3+5=8
+ 我们方程的右侧现在将是 $-b_i*a_i^3$

最后，我们将相应调整矩阵以考虑这些值。一切都准备好了，让我们来解它！

```python

k=6

    line=[
        F(received_codeword[i]),
        F(received_codeword[i]*xs[i]),
        F(received_codeword[i]*pow(xs[i],2)),

        F(-xs[i]),
        F(-pow(xs[i], 2)),
        F(-pow(xs[i], 3)),
        F(-pow(xs[i], 4)),
        F(-pow(xs[i], 5)),
        F(-pow(xs[i], 6)),
        F(-pow(xs[i], 7)),
        F(-pow(xs[i], 8)),
    ]
    lines.append(line)

A=Matrix(F,lines)
print(f"矩阵:\n{A}")
B=vector(F,results)
X=list(A.solve_right(B))

E=R(X[:3]+[1]) #e0-e2
Q=R(X[3:]) #q0-q7
print("E: ",E)
print("Q: ",Q)

P=Q//E #/表示一个分式Q/E，//表示整除
print("P: ",P)
assert P.degree()==k-1
coefficients=P.coefficients(sparse=False) #非稀疏,也返回多项式值为0的
recovered_message=[chr(m) for m in coefficients]
print("消息: ",recovered_message)
```

## 结论

我们成功探索了 Reed-Solomon 编码和解码的工作原理，从将信息编码为多项式，检测错误，并最终使用 Berlekamp-Welch 算法进行纠正。这些原理不仅仅是理论，它们构成了现实世界中如 CD、二维码和空间通信等错误纠正技术的核心基础。

但除了经典错误纠正之外，这些思想在密码学证明系统中也至关重要。例如，在快速 Reed-Solomon 交互预言机证明（FRI）协议中，Reed-Solomon 编码的一个变体被用于高效地检查多项式的低次性质。FRI 不是发送整个多项式，而是依赖随机采样和错误纠正技术，使验证者相信一个函数接近低次多项式，从而实现简洁且可扩展的零知识证明（ZKPs）。这种方法支撑了现代密码学系统如 STARKs，使多项式承诺方案即使在非常大的计算中也能保持高效。

Reed-Solomon 编码的核心，不仅仅是错误纠正，它既是一门经典又是一门现代计算的基础工具，连接了编码理论、密码学和证明系统这三个领域。无论是恢复损坏的信息，还是在区块链中证明计算的合法性，多项式的力量都无可否认。
